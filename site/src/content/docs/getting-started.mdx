The **EURIDICE DataLab** teaches practical data skills the way they are
actually used: by writing and running code against real datasets, with
instant feedback. It is built and maintained by **IIIM** (Icelandic Institute
for Intelligent Machines) as part of the EU-funded **EURIDICE** project.

## Who is this for?

Working professionals and students **without prior programming experience**
who want hands-on skills in exploratory data analysis, data science and
machine learning. If you can use a spreadsheet, you can start here.

## How learning works

Every lesson page embeds a **live notebook** — a mix of explanation and code
cells you run yourself with **Shift + Enter**. You can edit anything and
re-run it; experimenting is the point. Your changes are kept in your
browser, and the **↺ Reset this notebook** button under every notebook
restores the original — so you can never break it permanently.

Graded exercises give you **instant feedback**: store your answer in a
variable, run the check, and you immediately see ✅ or ❌ plus a hint.

## The tracks

| Track | What you'll be able to do | Time |
|---|---|---|
| 1 · Python & Data Foundations | Run notebooks, choose the right chart, diagnose missing data | ~3 h |
| 2 · Exploratory Data Analysis | Load, clean, summarise and visualise a real dataset — and know how sure you can be | ~3 h |
| 3 · Machine Learning Fundamentals | Train, compare and audit models; write a model card; export your portfolio | ~5 h |

Work through them in order if you're new; jump straight to a track if you're not.

**If a lesson moves too fast,** the [Learn more](/learn-more/) page collects
free guides for Python basics, pandas, charts and fairness — keep it open in
a second tab.
