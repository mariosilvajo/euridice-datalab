**For complete beginners.** No programming experience assumed — if you have
never written a line of code, this is your on-ramp.

## What you'll be able to do

- Use a Jupyter notebook confidently (the tool every data scientist uses daily)
- Store and manipulate values with variables and lists
- Repeat work with loops
- **Choose the right chart** for a question — and spot charts that mislead
- **Diagnose missing data** with `missingno`, and judge what it does to your conclusions

## Lessons

| # | Lesson | Time |
|---|---|---|
| 1 | [Your first notebook](/tracks/foundations/01-first-notebook/) | ~45 min |
| 2 | [Choosing the right chart](/tracks/foundations/02-choosing-charts/) | ~75 min |
| 3 | [Seeing what's missing](/tracks/foundations/03-missing-data/) | ~75 min |

Lessons 2 and 3 are where beginners usually leap ahead: most courses teach
you to *make* a chart, few teach you which chart to make or what your data
isn't telling you.

## How to work

Run every cell yourself, change things, break things, re-run. If you get
lost, **↺ Reset this notebook** (under every notebook) restores the
original, so nothing you do can go wrong. Curiosity beats caution here.
