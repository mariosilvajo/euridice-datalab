Beyond the guided lessons, the DataLab gives you the **full environment** to
explore freely — the same tools professional data scientists use, running
entirely in your browser.

- **[Open JupyterLab ↗](/lab/lab/index.html)** — the complete IDE: file
  browser, multiple notebooks, all preloaded datasets in the `data/` folder.
- **[Open the console ↗](/lab/repl/index.html?kernel=python&toolbar=1)** — a
  quick Python scratchpad for one-liners and experiments.

Your changes are saved **in your own browser** between visits. To keep a
notebook permanently, download it: *File → Download*.

## Quick console

Try Python right here — type an expression and press Enter. It is a
scratchpad: it **can't see the lab's files**, so for the datasets and the
DataLab helpers, open JupyterLab above.
